*CC-011 — Add BreadcrumbList structured data to provider profile pages* (S)
The provider profile page already emits one JSON-LD block (a Service schema, from CC-004) but nothing else. BreadcrumbList is one of the highest-value, lowest-risk schema types — it tells search engines the navigational path to a page (Home → Browse → provider name), which can replace a raw URL with a breadcrumb trail in search results. Add a second <script type="application/ld+json"> block to the same file, using data already in scope — no new query, no schema change, no new copy.
_Why this one:_ the natural next increment on CC-004's already-shipped pattern — one more script tag in a file that already emits one, a distinct schema type serving a distinct purpose.
_Devil's advocate:_ schema isn't a direct ranking factor and the effect is only visible once Google actually serves these pages in search results, which may be a while at this pilot's size. Survives anyway — a few minutes of work on infrastructure this file already has, no realistic downside.
